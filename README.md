# Ever wondered how injuries truly impact a team's performance?

This project explores the relationship between NFL player injuries and team performance, focusing on how injuries affect the Expected Points Added (EPA).

The project aims to answer several questions:

 - Do certain injury types have a greater impact on team performance than others?
 - How does an injury to a specific position group affect a team's Expected Points Added (EPA)?
 - How does the number of players injured or games missed influence team performance?
 - Did team Net EPA changes differ during the 2020 NFL season compared to other seasons?

Using NFL injury and performance data, this project applies statistical modeling and data visualization to investigate the relationship between player injuries and team performance.
